The Engine

What AEGIS Generates

Risks

FAIR-quantified with TEF, Vulnerability, LEF, Primary & Secondary Loss, ALE in dollars. Priority-ranked by org size thresholds.

Policies

AI-generated per gap domain. Includes purpose, scope, roles, policy statements with framework clause references, review frequency.

Tasks

Grouped by domain with subtasks per control. Step-by-step implementation guides. Due dates and priority auto-assigned.

Mappings

Bidirectional cross-framework mapping. NESA ↔ ISO 27001 ↔ NIST 800-53. Answer once, map everywhere.

Evidence Analysis

AI scores evidence (1-10). Shows what it proves, what's missing, and recommendations. Min 5/10 to proceed.

Auto-Closure

Control completed = linked risk auto-closes. Compliance auto-recalculates. Sidebar progress updates in real-time.

Built on Anthropic Claude AI — 75% automation rate

Workflow 4

Risk Register — FAIR Breakdown

FAIR Quantification

TEF (Threat Frequency)   : 0.75/yr
Vulnerability          : 60%
LEF (Loss Frequency)    : 0.45/yr
Primary Loss           : $180,000
Secondary Loss         : $95,000
ALE (Annual Exposure)   : $123,750
  • Treatment: Mitigate / Accept / Transfer / Avoid
  • Sorted by priority: Critical → High → Medium → Low
  • Total ALE / Open ALE summary at top

Governance & Auto-Closure

  • Linked Controls: Tree hierarchy — domain task as parent, subtask controls as children
  • Change Requests: All risk changes require approval
  • Admin approves/rejects with reason
  • Field-level changes tracked in audit trail

Auto-Closure

When linked control subtask is completed → risk auto-closes. AEGIS logs in audit trail. Residual risk drops to 1.

Workflow 5

Controls — 3-Stage Lifecycle

Grouped tasks by domain → Expand subtask → Implement → Upload Evidence → Get Approved

Implement

Step-by-step instructions, related policies, framework requirements

→

Evidence

File upload, AI analysis (score 1-10), min 5/10 to proceed

→

Review

Admin approves/rejects, completed = locked with green tick

Implementation Guide

  • Overview of what's needed
  • Numbered steps: Action, How-to, Deliverable
  • Evidence format and tips
  • Related policies listed
  • Framework requirement box with cross-framework mappings

Auto-Completion Chain

  • Subtask completes → locked with green tick
  • All subtasks done → parent task auto-completes
  • Linked risk auto-closes
  • Compliance recalculated across frameworks
  • Sidebar progress updates via triggerRefresh()
